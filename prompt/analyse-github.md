# GitHub 项目分析需求模板

把下面内容发给 AI，填上占位符即可。也可以只发「URL + 一句话用途」。

---

项目：<GitHub 仓库 URL>
用途：<你想拿它做什么 / 解决什么问题>
方式：<分析 | 试用 | 安装 | 对比>   ← 可选，不写默认"分析 + 建议"
关注点：<可选，比如安全性 / license / 性能>

默认流程（AI 会自动执行）：
1. 项目概览：做什么、star/fork、最近提交、license、是否活跃
2. 技术栈与架构：语言、框架、模块结构、关键依赖
3. 质量与维护度：文档、测试、CI、issue/PR 活跃度
4. 安全与合规：依赖漏洞、敏感信息、license 适用性
5. 适用性：是否符合需求、与替代品对比、上手成本
6. 结论与建议：结论先行，值不值得用、风险、替代方案

产出：结论 → 分项 → 风险 → 建议（若要安装，附安装步骤 + 依赖 + 坑）

确认：涉及 clone/install/运行/改环境时，先给方案等确认，不擅自操作。
